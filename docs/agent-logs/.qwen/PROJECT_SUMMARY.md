# Project Summary

## Overall Goal
Transform the Deeper Research Synthetic application into a modern, professional, and highly functional AI-powered content generation platform with comprehensive dark mode theming, improved UI/UX, and enhanced features for academic papers, podcast narratives, and risk assessments.

## Key Knowledge
- **Technology Stack**: Node.js/Express.js backend with React 18 frontend
- **AI Integration**: Google Gemini AI for content generation with Server-Sent Events (SSE) streaming
- **UI Framework**: React with modern design principles, featuring dark mode Dracula theme
- **Content Frameworks**: PROJECT_DEEPDIVE (academic papers), PROJECT_SYNTHESIC (podcast episodes), PROJECT_BENCHMARK (risk assessments)
- **Build Commands**: `npm run dev` for both frontend and backend, runs on ports 3001 (backend) and 5173 (frontend)
- **API Key**: Requires GEMINI_API_KEY in backend/.env file
- **Security**: Comprehensive input validation, ReDoS protection, rate limiting
- **Architecture**: Three-tier architecture with React frontend → Express API → Gemini AI generation
