Deeper Research Synthetic Project Context

Project Overview:
- AI-powered content generation framework
- Transforms raw data into academic papers, podcast narratives, and risk assessments
- Uses Google Gemini AI for content generation
- Real-time streaming generation with Server-Sent Events (SSE)

Architecture:
- Backend: Node.js/Express.js API server
- Frontend: React 18 application
- AI Integration: Google Gemini API

Project Structure:
- backend/: Express.js API server with services for generation, validation, and framework management
- frontend/: React application with components for project management and content generation
- data/: Framework templates and generated reports
- docs/: Documentation files
- .github/workflows/: GitHub Actions for CI and AI-powered triage

Key Features:
- PROJECT_DEEPDIVE: Academic papers with citations (10,000+ words)
- PROJECT_SYNTHETIC: Podcast scripts with narrative storytelling (15,000+ words)
- PROJECT_BENCHMARK: Risk assessments with DEFCON ratings (5,000+ words)

Security Measures:
- Input validation and sanitization
- ReDoS (Regular Expression Denial of Service) protection
- Rate limiting and resource management
- Secure API key handling
- CORS configuration with security in mind
